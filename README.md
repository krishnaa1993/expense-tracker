# Expense Tracker

A simple and responsive expense tracker built with HTML, CSS, and JavaScript. The application allows users to add, edit, and delete income and expense transactions while automatically calculating total income, total expenses, and balance.

## Features

- Add income and expense transactions
- Edit existing transactions
- Delete transactions
- Automatic income, expense, and balance calculations
- Input validation
- LocalStorage for saving transactions
- Responsive design
- Clean and simple user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How It Works

Users can enter a transaction title, amount, and transaction type.

The application then:

1. Adds the transaction to the transaction list.
2. Updates total income or expenses.
3. Calculates the current balance.
4. Saves the transaction data in LocalStorage.
5. Restores saved transactions when the page is refreshed.
